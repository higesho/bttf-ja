# バック・トゥ・ザ・フューチャー ザ・ゲーム 日本語化プロジェクト

テルテール・ゲームズの「Back to the Future: The Game」を日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
全 5 エピソードのうち、エピソード1から順に日本語化しています。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/bttf-ja/
- ダウンロード: [リリース](https://github.com/higesho/bttf-ja/releases)
- 日本語化プロジェクトの一覧: https://higesho.github.io/ja/

パッチはゲームのフォルダに DLL をひとつ置くだけで日本語になり、消せば英語に戻ります。ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
